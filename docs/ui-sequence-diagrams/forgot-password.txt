@startuml
title 2. Login - Forgot Password

participant MobileApp as "Mobile App"
participant user_otp as "user-otp (Backend)"
participant egov_user as "egov-user (Backend)"

activate MobileApp
note over MobileApp: User clicks "Forgot Password" and enters Phone Number

MobileApp -> user_otp: Call to /user-otp/v1/send/ (Phone Number)
activate user_otp
user_otp --> MobileApp: OTP Sent Confirmation
deactivate user_otp

note over MobileApp: On request completion, redirect to OTP Input Screen (2.a.ii)

note over MobileApp: User enters OTP
note over MobileApp: Redirect to Password Reset Screen (2.a.iii)

MobileApp -> egov_user: Call to /user/password/nologin/_update (OTP, New Password)
activate egov_user
egov_user --> MobileApp: Password Update Confirmation
deactivate egov_user

deactivate MobileApp

@enduml
